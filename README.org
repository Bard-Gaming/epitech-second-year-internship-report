** About

** Building the Report
#+begin_quote
[!IMPORTANT]
Building the project requires ~pdflatex~
(amongst other dependencies).
All dependencies are present in
the ~texlive-bin~ and ~texlive-binextra~
packages.
#+end_quote

*** Default Build

To build the report from source, all you need
to do is run ~make~:

#+begin_src shell
make
#+end_src

You can then (optionnally) run:

#+begin_src shell
make clean
#+end_src

to delete all temporary build files.

*** Rebuilding

If you wish to rebuild the report
from scratch, all you need to do
is run:

#+begin_src shell
make re
#+end_src
